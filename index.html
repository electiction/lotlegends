— The Idea

เทรดเดอร์ที่จริงจัง
สมควรได้รับรางวัลที่ เงียบงาม

The Lot Legends คือโปรแกรมสะสม Lot สำหรับเทรดเดอร์ XM ที่เชื่อว่าความสำเร็จไม่จำเป็นต้องส่งเสียงดัง เราคัดสรรของรางวัลทุกชิ้นจากแบรนด์ที่ผ่านการพิสูจน์ด้วยกาลเวลา เพราะของที่ดี ไม่ต้องอวด ก็รู้ว่าดี

ทุก Lot ที่คุณเทรด ถูกบันทึกอย่างโปร่งใส เปลี่ยนเป็นรางวัลที่จับต้องได้จริง — โดยไม่มีเงื่อนไขซ่อนเร้น

— How It Works

สี่ขั้น. ง่ายอย่างที่ควรเป็น.

  1. 01

    สมัครภายใต้ IB ของเรา

    คลิกลิงก์เพื่อเปิดบัญชี XM ใหม่ภายใต้ Partner Code ของเรา ใช้เวลาไม่ถึง 5 นาที

  2. 02

    เทรดในแบบของคุณ

    ทุก Lot ที่คุณเทรด (ไม่ว่า Forex, Gold, Index) จะถูกบันทึกอัตโนมัติ

  3. 03

    ตรวจสอบความคืบหน้า

    ดู Dashboard ส่วนตัวได้ตลอดเวลา — โปร่งใส ไม่มีเงื่อนไขแอบแฝง

  4. 04

    รับรางวัลถึงบ้าน

    เมื่อถึงระดับที่ต้องการ ทักมาแจ้งเลือกรางวัล จัดส่งฟรีทั่วไทย

— Questions

คำถาม
ที่พบบ่อย

ต้องเทรดประเภทไหนถึงจะนับ Lot?

นับทุก Instrument ที่ XM เปิดเทรด — Forex, Gold, Crypto, Index, Stocks ตามมาตรฐาน Standard Lot ของ XM

Lot ที่สะสมไว้หมดอายุไหม?

ไม่หมดอายุ คุณสะสมในจังหวะของคุณเอง ไม่ต้องเร่งรีบ ไม่ตะโกนเรียกร้อง

เคยมีบัญชี XM อยู่แล้ว เข้าร่วมได้ไหม?

หากยังไม่ได้อยู่ใต้ IB ของเรา ต้องเปิดบัญชีใหม่ภายใต้ Partner Code เพื่อให้ระบบนับ Lot ได้ถูกต้อง

รางวัลส่งทั่วประเทศไหม?

ส่งฟรีทั่วประเทศไทยผ่าน Kerry / Flash Express พร้อมประกันสินค้า 100%

เลือกของรางวัลแทนได้ไหม?

ได้ในมูลค่าเทียบเท่า เช่น แทน iPhone ด้วย iPad หรือทอง สามารถพูดคุยกับทีมได้
